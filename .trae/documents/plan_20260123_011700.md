# 实现TradingWeb Vue3 KLine行情展示页面

## 1. 项目初始化
- 在`e:\Crypto\Admin.NET`目录下创建`TradingWeb`文件夹
- 使用Vite初始化Vue3 + TypeScript项目
- 安装必要依赖：
  - `echarts`：用于KLine图表展示
  - `@microsoft/signalr`：用于连接后端SignalR服务
  - `axios`：用于HTTP请求
  - 其他Vue3相关依赖

## 2. 项目结构设计
```
TradingWeb/
├── src/
│   ├── api/             # API请求相关
│   ├── components/      # 组件
│   │   └── KLineChart/  # KLine图表组件
│   ├── hooks/           # 自定义hooks
│   │   └── useSignalR.ts # SignalR连接管理
│   ├── services/        # 服务层
│   │   └── marketService.ts # 行情数据服务
│   ├── types/           # TypeScript类型定义
│   ├── views/           # 页面
│   │   └── MarketView.vue # 行情展示页面
│   ├── App.vue          # 根组件
│   └── main.ts          # 入口文件
└── vite.config.ts       # Vite配置
```

## 3. 核心功能实现

### 3.1 KLine图表组件
- 使用Echarts实现KLine图表
- 支持多种时间周期切换（1m、5m、15m、1h、4h、1d等）
- 实现图表缩放、拖拽等交互功能
- 支持技术指标展示（可选）

### 3.2 SignalR连接管理
- 创建SignalR连接实例
- 实现自动重连机制
- 订阅指定交易对的行情更新
- 处理实时价格数据

### 3.3 行情数据服务
- 封装KLine数据获取API
- 处理历史KLine数据
- 整合实时行情更新
- 数据格式转换（适配Echarts）

### 3.4 行情展示页面
- 实现交易对选择功能
- 集成KLine图表组件
- 展示当前价格、涨跌幅等信息
- 实现时间周期切换

## 4. 后端接口对接
- 后端SignalR服务地址：`/MarketHub`
- 订阅单个交易对：`SubscribeSymbol(symbol)`
- 接收实时行情：`SymbolUpdate`事件
- KLine数据API：需要根据后端实现调整
