# 修改HandleKlineUpdateAsync方法实现K线周期结束时才存储数据

## 问题分析
当前的`HandleKlineUpdateAsync`方法会在每次收到K线数据更新时都存储或更新数据库中的K线记录，这导致同一个K线周期的数据被多次更新。用户希望只在K线周期结束时存储一次数据，并且存储后不再更新。

## 解决方案

### 1. 检查K线是否结束
Binance.Net的WebSocket K线数据通常包含一个表示K线是否结束的字段（如`IsFinal`或`Final`）。我将在`HandleKlineUpdateAsync`方法中添加对这个字段的检查，只有当K线结束时才执行存储操作。

### 2. 只存储一次数据
- 当K线结束时，检查该K线是否已经存在于数据库中
- 如果不存在，则插入新的K线记录
- 如果已经存在，则不再更新（因为K线周期结束后数据不会再变化）

### 3. 修改步骤

#### 步骤1：修改`HandleKlineUpdateAsync`方法
- 添加对K线结束字段的检查
- 调整存储逻辑，只在K线结束且记录不存在时插入数据

#### 步骤2：测试验证
- 运行系统，验证K线数据只在周期结束时存储一次
- 检查数据库中的K线记录，确保每个K线周期只有一条记录

## 代码修改方案

```csharp
public async Task HandleKlineUpdateAsync(string symbol, string interval, object klineData)
{
    try
    {
        // 动态处理不同类型的K线数据
        var dataDict = Newtonsoft.Json.JsonConvert.DeserializeObject<Newtonsoft.Json.Linq.JObject>(Newtonsoft.Json.JsonConvert.SerializeObject(klineData));
        
        // 检查dataDict和Data属性是否为null
        if (dataDict == null || dataDict["Data"] == null)
        {
            Console.WriteLine($"K线数据为空: {symbol} {interval}");
            return;
        }
        
        var kline = dataDict["Data"];
        
        // 检查K线是否结束
        bool isFinal = kline["IsFinal"] != null && (bool)kline["IsFinal"];
        
        // 只有当K线结束时才存储数据
        if (isFinal)
        {
            // 转换为Candlestick实体
            var candlestick = new Candlestick
            {
                Symbol = symbol,
                Interval = interval,
                OpenTime = kline["OpenTime"] != null ? (long)kline["OpenTime"] : 0,
                Open = kline["OpenPrice"] != null ? (decimal)kline["OpenPrice"] : 0,
                High = kline["HighPrice"] != null ? (decimal)kline["HighPrice"] : 0,
                Low = kline["LowPrice"] != null ? (decimal)kline["LowPrice"] : 0,
                Close = kline["ClosePrice"] != null ? (decimal)kline["ClosePrice"] : 0,
                Volume = kline["Volume"] != null ? (decimal)kline["Volume"] : 0,
                CloseTime = kline["CloseTime"] != null ? (long)kline["CloseTime"] : 0,
                QuoteAssetVolume = kline["QuoteVolume"] != null ? (decimal)kline["QuoteVolume"] : 0,
                NumberOfTrades = kline["TradeCount"] != null ? (int)kline["TradeCount"] : 0,
                TakerBuyBaseAssetVolume = kline["TakerBuyBaseVolume"] != null ? (decimal)kline["TakerBuyBaseVolume"] : 0,
                TakerBuyQuoteAssetVolume = kline["TakerBuyQuoteVolume"] != null ? (decimal)kline["TakerBuyQuoteVolume"] : 0
            };

            // 检查是否已存在该K线数据
            var existing = await _candlestickRepo.GetFirstAsync(
                x => x.Symbol == symbol && x.Interval == interval && x.OpenTime == candlestick.OpenTime);

            // 只在记录不存在时插入，不再更新
            if (existing == null)
            {
                // 插入新K线数据
                await _candlestickRepo.InsertAsync(candlestick);
            }
        }
    }
    catch (Exception ex)
    {
        Console.WriteLine($"处理K线数据失败: {ex.Message}, Symbol: {symbol}, Interval: {interval}");
    }
}
```

## 预期效果
1. K线数据只会在K线周期结束时被存储一次
2. 每个K线周期在数据库中只有一条记录
3. 减少数据库写入操作，提高系统性能
4. 确保K线数据的完整性和准确性
